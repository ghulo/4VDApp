# Polish: every screen, setup guide, search, weekly email (part 3 of the rebrand) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish the "real product" round: a weekly report by email, a Ctrl/Cmd+K command palette, a setup guide for the owner, a welcome for new staff, and every screen checked and fixed in both themes.

**Architecture:** The weekly report reuses the daily summary's building blocks (shop-time scheduling, a once-a-week claim in `settings`, the reports repository) and the email outbox; a per-person `email_weekly_report` switch lives on `users`. The command palette and setup guide are dashboard-only; their logic (matching, step completion) sits in small pure modules with unit tests. The staff welcome is a three-card overlay in the app, shown once per person per device.

**Tech Stack:** Express + Kysely + Vitest (backend), React + Vite + Vitest (dashboard), Expo (app).

**Spec:** `docs/superpowers/specs/2026-10-02-rebrand-accounts-design.md` (sections 2 "Email" and 3)

## Global Constraints

- Weekly report: Monday at the daily summary hour (`dailySummaryHour`, shop time), covering the previous Monday–Sunday, sent once per week even across restarts; to admins who haven't switched it off.
- Command palette: Ctrl+K on Windows/Linux, Cmd+K on Mac; Esc closes; arrow keys + Enter; `/` focuses the page's search box when there is one and focus isn't in a field.
- Setup guide steps: shop details (address or phone), logo, first product, invite someone (another user or an open invite), alerts on (a device). It hides itself when all are done, and can be hidden for good.
- Staff welcome: three cards (sell, products, requests), "Skip" on every card, shown once per person on each device.
- Sentence case, no all-caps, no "A · B" separators; both themes; phone widths.

## Review Focus

- The weekly report hour passes while the server is asleep or restarts → still sent once that Monday, never twice (Task 1 test).
- A person switched the weekly email off → nothing queued for them (Task 1 test).
- Typing in the palette faster than search results arrive → results belong to the latest query (Task 2: query key includes the text).
- `/` pressed inside a text field → types a slash, doesn't jump (Task 2 test).
- Setup guide on a fresh shop with no data at all → shows all steps, no crash on empty lists (Task 3 test).
